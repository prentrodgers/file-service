8/18/26 Claude created a web site to host my music files.
    I found out that X turns all http:// in a post to https:// automatically. All my music now is inaccessible to the posts I've made for the past few months. I asked Claude to build me a free site on Cloudflare. He did it in a couple of hours. I had other stuff going on at the time. 

    Cloudflare buit a template site based on the Bear Blog minimalist style. and posted it to github as https://github.com/prentrodgers/file-service. Claude then took that and asked a ton of questions, and built a site with a Home page, a Listen page, a Watch (for video) page, a Notes page,  and an About page that points to the Substack site. 
    Then he created an R2 bucket on Cloudflare, copied all my recent work there, and told me when to push it. Once it was pushed the github actions took over and uploaded it to the site, now live here: https://microtonalnotes.net/

    To push it:
        eval $(op signin)
        git push # may open Edge window to accept github auth
    git pull
    
    There are a few things I would change, but there is time later to refine the wording and make it personal. 
    1. Change the example on the home page to a short_repeats version and a long version 
    2. Include a LilyPond version of a short_repeats chorale 
    3. Build out the Notes page more
    4. Refine the description of the Werckmeister II and 12 TET entries on Listen to explain the Triangle wave realization. 

    When you create an album, use this bash script to move them to the R2 storage bucket:
        ./scripts/publish-album.sh ~/Dropbox/Uploads/c8-08-03-26
